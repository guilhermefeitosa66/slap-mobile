Dois ajustes na primeira tela.

## Mudou

- **Na primeira abertura, sem nenhum inventário, o botão "Novo" não aparece.** A tela já oferece
  as duas origens no centro — ler o QR code de outro aparelho ou importar de arquivo —, e o botão
  levava ao mesmo lugar. Dois caminhos para a mesma coisa, antes de existir qualquer inventário,
  é só uma escolha a mais para quem ainda não sabe o que o aplicativo faz. Com o primeiro
  inventário criado, ele passa a aparecer.

- **Puxar a lista de cima para baixo atualiza.** Relê os inventários e pergunta de novo se há
  versão nova — é o jeito de conferir sem fechar e abrir o aplicativo. Se você tinha dispensado o
  aviso com "Agora não", ele volta: quem puxou para atualizar pediu para saber.

## Atualizar

Instale o APK **por cima** da versão anterior: os inventários ficam. **Não desinstale** para
atualizar — desinstalar apaga o que ainda não foi trocado com outro aparelho.

Quem nunca instalou: baixe `slap-1.2.3.apk` — é um arquivo só, para qualquer celular Android — e
siga o
[passo a passo de instalação](https://github.com/guilhermefeitosa66/slap-mobile/blob/main/docs/instalacao.md).

Para conferir que o arquivo é este: a soma SHA-256 está em `SHA256SUMS.txt`, e o certificado de
assinatura tem a impressão digital SHA-256

```
{{certificado}}
```

a mesma de todas as versões.

## O que ainda não faz

- **Não atualiza o SUAP.** Gera as planilhas para quem faz a atualização.
- **Não lê `.xls`** (Excel 97-2003). Abra a planilha e salve como `.xlsx` ou `.csv`.
- **Não sincroniza pela internet** — só na mesma rede local, por projeto. Redes que isolam os
  aparelhos entre si não funcionam; nesse caso, um dos celulares compartilha a conexão (ponto de
  acesso) e os outros se conectam nele.
- **Só Android**, 7.0 ou mais novo, com processador ARM. Ainda não está na Play Store nem há
  versão para iPhone.
- **Em tablet**, a interface é a mesma do celular, mais larga.
